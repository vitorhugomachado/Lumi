Você é o engenheiro principal do projeto **Lumi**.

Sua tarefa é construir a primeira versão funcional de uma aplicação web/PWA conversacional por voz para crianças pequenas, inicialmente como protótipo para testes com adultos.

## VISÃO DO PRODUTO

Lumi é um personagem virtual amigável que conversa por voz com crianças pequenas para estimular linguagem, vocabulário e pequenas frases.

O produto deverá futuramente ser usado por crianças de aproximadamente 2 a 4 anos sob supervisão dos responsáveis.

Nesta primeira versão, NÃO implementar diagnóstico médico, terapia, promessas de desenvolvimento ou testes clínicos.

---

# OBJETIVO DA V0

Construir um protótipo funcional com este fluxo:

Responsável abre o site

→ tela de boas-vindas

→ configura perfil local da criança

→ entra na tela do Lumi

→ autoriza microfone

→ inicia conversa

→ Lumi recebe áudio

→ IA responde

→ áudio da resposta é reproduzido

→ personagem muda visualmente entre:
idle / listening / thinking / speaking

# MOTOR DE CONVERSA

Criar um prompt de sistema dinamicamente usando:

- nome
- idade
- interesses
- palavras conhecidas

O prompt deve instruir Lumi a:

- falar português brasileiro;
- usar frases muito curtas;
- uma pergunta por vez;
- dar espaço para resposta;
- ser extremamente amigável;
- incentivar sons e palavras;
- expandir naturalmente o que a criança diz;
- nunca repreender pronúncia;
- nunca dizer "você errou";
- usar assuntos concretos;
- brincar com animais, objetos, comida e sons;
- não fazer longas explicações.

# MODO MOCK

Isso é obrigatório.

Criar:

NEXT_PUBLIC_VOICE_PROVIDER=mock

ou:

NEXT_PUBLIC_VOICE_PROVIDER=gemini

Com `mock`, deve ser possível navegar por toda a experiência sem Gemini.

No modo mock:

usuário clica no microfone

→ listening durante ~2 segundos

→ thinking

→ speaking

→ reproduzir ou mostrar uma resposta simulada.

Exemplo:

"Oi! Eu sou o Lumi!"

Isso permite desenvolver UI sem gastar API.
